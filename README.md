# AgVpsUnlock — доступ к Antigravity из любого региона

AgVpsUnlock снимает региональные ограничения Antigravity: приложение работает так,
будто ваш компьютер находится в поддерживаемом регионе. Всё в один клик — без
ручной настройки VPN и системных файлов.

## Что потребуется

- Windows 10/11 (x64)
- Установленная Antigravity
- **IP сервера** и **Токен доступа** — выдаются при покупке подписки на одно устройство

Подписка и продление — через личные сообщения.

## Быстрый старт

1. Запустите `AgVpsUnlock.exe` от имени администратора.
2. Введите полученные IP и Токен → **Сохранить**.
3. Нажмите **Проверить сервер** — дождитесь зелёного статуса.
4. Нажмите **Применить патч**, запустите Antigravity и войдите в аккаунт Google.

Сводный индикатор под заголовком подсказывает текущее состояние:
«Всё готово к работе» / «Требуется патч» / «Не настроено».

## Важно знать

- Один токен действует на одном устройстве.
- После обновления Antigravity просто снова нажмите **Применить патч**.
- Кнопка **Обновить** перечитывает список установленных копий.
- Полный журнал операций — внизу окна; кнопка **Копировать всё** помогает приложить
  его к обращению в поддержку.
- Токен можно сменить/продлить — просто замените его в поле и сохраните.
