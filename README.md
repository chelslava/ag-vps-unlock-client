## Что это

AgVpsUnlock снимает региональные ограничения Antigravity: приложение работает
так, будто ваш компьютер находится в поддерживаемом регионе. Всё в один клик —
без ручной настройки VPN и системных файлов.

## Как купить

1. Нажмите кнопку **«Купить подписку»** выше или напишите [@AGUnlock_bot](https://t.me/AGUnlock_bot)
2. Оплатите по СБП
3. Получите **IP** и **Токен** автоматически
4. Следуйте инструкции в приложении

## Быстрый старт

| Шаг | Действие |
|-----|----------|
| ① | Запустите `AgVpsUnlock.exe` от администратора |
| ② | Введите IP и Токен → **Сохранить** |
| ③ | **Проверить сервер** → зелёный статус |
| ④ | **Применить патч** → запустите Antigravity |
